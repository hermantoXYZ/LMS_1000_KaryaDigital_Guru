
# EDU LMS
## Learning Management System – Karya Digital Guru

**EDU LMS** merupakan karya digital berupa platform Learning Management System (LMS) yang dikembangkan untuk mendukung proses pembelajaran digital secara terintegrasi, mulai dari pengelolaan kelas, penyediaan materi, aktivitas pembelajaran, evaluasi, hingga monitoring hasil belajar peserta didik.

# 2. LATAR BELAKANG

Perkembangan teknologi digital mendorong perubahan dalam penyelenggaraan proses pembelajaran. Guru tidak hanya dituntut untuk menyampaikan materi, tetapi juga mampu mengelola aktivitas pembelajaran, menyediakan sumber belajar digital, melakukan evaluasi, serta memantau perkembangan peserta didik.

Namun, pengelolaan pembelajaran sering kali masih menggunakan berbagai aplikasi dan media yang terpisah. Kondisi tersebut dapat menyebabkan aktivitas pembelajaran kurang terintegrasi dan menyulitkan guru dalam melakukan monitoring.

Oleh karena itu, diperlukan sebuah platform pembelajaran digital yang mampu mengintegrasikan berbagai aktivitas pembelajaran dalam satu sistem.

EDU LMS dikembangkan sebagai solusi digital untuk membantu guru mengelola proses pembelajaran secara lebih sistematis, efektif, dan terintegrasi dengan memanfaatkan teknologi informasi dan Generative AI.

# 3. TUJUAN PENGEMBANGAN

1. Mengembangkan platform pembelajaran digital yang terintegrasi.
2. Mempermudah guru dalam mengelola kelas dan peserta didik.
3. Menyediakan akses materi pembelajaran secara digital.
4. Memfasilitasi pemberian tugas dan evaluasi pembelajaran.
5. Membantu guru memantau perkembangan hasil belajar.
6. Mengoptimalkan pemanfaatan Generative AI dalam pengembangan pembelajaran.

## 6.3 Persiapan Lingkungan Pengembangan

Perangkat yang diperlukan:

- Python 3.2
- Django 5.2
- MySQL Server
- MySQL Client
- Visual Studio Code/Antigravity
- Git
- Browser

### Instalasi Django

```bash
# Membuat virtual environment
python -m venv venv

# Aktivasi virtual environment (Mac/Linux)
source venv/bin/activate

# Aktivasi virtual environment (Windows)
venv\Scripts\activate

# Instalasi Django
pip install django

# Instalasi MySQL driver
pip install mysqlclient

# Jika ada kendala di ENV Windows dapat  Jalankan perintah berikut di PowerShell:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### Membuat Project Django

```bash
django-admin startproject core .

# Membuat aplikasi
python manage.py startapp app

```

### Menjalankan Development Server

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Aplikasi dapat diakses melalui:

http://127.0.0.1:8000/
